# Complex II Myzozoa Analysis

Comparative analysis of mitochondrial Complex II subunit conservation and divergence across Myzozoa using MMseqs2 and MUSCLE5.

## Overview

This repository contains the scripts and notebooks used to:

1. Perform MMseqs2 homology searches across a custom Myzozoa database.
2. Filter and annotate hits with taxonomic metadata.
3. Generate conservation visualisations.
4. Construct multiple sequence alignments (MSA) using MUSCLE5 for downstream phylogenetic analysis.

## Structure

- `notebooks/` – Original exploratory Jupyter notebooks.
- `scripts/` – Runnable Python scripts for reproducing the analyses.
- `core_functions/` – Shared helper functions.

## Requirements

- Python 3.x
- MMseqs2
- MUSCLE5
- WSL (for running Linux tools on Windows)
